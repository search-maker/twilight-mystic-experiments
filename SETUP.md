Create a public repository named `twilight-mystic-experiments` under the `search-maker` account and initialize it with a README so that `main` has one commit. Do not add a license or `.gitignore`; the prepared package supplies those files.

Ensure the ChatGPT GitHub app has access to the new repository. After that, the prepared files can be published as one atomic commit, causing only one contract-CI cycle.

Do not create the authorization branch and do not edit `experiment/authorization.json`. Scientific execution remains disabled until the public repository's exact-head contract workflow is green and a separate one-purpose authorization commit is prepared.
