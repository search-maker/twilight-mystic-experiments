# Tier-1 proposal bridge

This bridge consumes only a successful, first-attempt ordinal-6 timeout-continuation analysis. It validates exactly six computational reference anchors, keeps them excluded from fitting, and emits a deterministic tier-1 proposal containing 48 geometries, 96 ALIS cases, and 6.96 billion configured photon histories.

The bridge never runs MYSTIC and never trains a surrogate. Its output is not an authorization. A separate one-purpose authorization, a separate manual scientific dispatch, independent audit, internal holdout evaluation, and later observation validation are still required.
