# Tier-1 continuation wave 1 v2 preparation

This package prepares—but does not authorize or dispatch—the first bounded continuation wave for the immutable Tier-1 ordinal-2 evidence.

## Frozen scope

- exact source base: `2cb23408e73fc8e8313d483a02d8e05c58de9cff`;
- exactly 20 preregistered geometries and blocks b3-b4 only;
- exactly 40 cases: 34 surrogate-training and 6 internal-holdout cases;
- preserved roles: 17 surrogate-training and 3 internal-holdout geometries;
- maximum configured wave budget: 5,100,000,000 photon histories;
- exact thresholds, stopping rules, zero-hit treatment, physical inputs, and evidence bindings inherited from the reviewed continuation-v2 package.

The preregistration preserves every original b1-b2 case identity and estimator. It uses only the already-frozen wave-1 seed subset. The seed proof covers ordinal-1 seeds, ordinal-2 seeds, and consumed probe seeds; all 40 wave seeds are unique and have zero overlap with that 196-seed historical registry.

## Refusal boundary

Generation and validation fail closed on scope, seed, budget, role, provenance, evidence-hash, malformed/partial evidence, duplicate-run, retry/attempt, and nonfinite-value drift. Each case contract permits one syntax validation, one solver invocation, attempt 1 only, and no retry.

`authorization.template.json` is intentionally disabled and unbound. This preparation allocates no ordinal or execution key, enables no authorization, and performs no workflow dispatch, scientific execution, GitHub Re-run, training, fitting, holdout opening, Tier-2 action, production action, or merge.
