# AVPS v2 recovery3 successor authorization-review infrastructure

This package adds a solver-free, read-only `pull_request_target` review for the exact one-file recovery3 successor authorization proposed by the successful recovery3 authorization-control proof.

It is infrastructure only. It does not allocate a scientific ordinal, create an authorization or dispatch ref, apply a seed to a scientific case, execute libRadtran/MYSTIC/uvspec, open AVPS results, admit richer Level-B atmosphere coordinates, access a protected holdout, use Taylor/Jerusalem or low-altitude protected residuals, or change production behavior.

The review binds control PR #716/head `d8cd4af807e7a8f11ed39fdc579ed92adf866aab`/run `33316848139`/artifact `9733949799` (`sha256:5fb50efa7adb1159c398766a36b5bff171d7f7ddc202eaad85fd261596a93103`), requires the future authorization PR to be an exact one-file direct child and byte-equal to `authorization.proposed.json`, validates consumed ordinals 41/42/43 and the native historical ordinal-42 seed-ledger path, rebuilds the 72 recovery3 candidate seeds, repeats tracked-tree and repository-global freshness scans after workflow quiescence, and independently proves that proposed successor ordinal 44 is still only a self-observation and that the non-self global maximum remains 43.

All richer Operational Atmosphere State v2 fields remain unadmitted to the fast Level-B mapper. `newMappingAuthorized` remains false for vertical profile, arbitrary spectral AOD, SSA, phase function, and aerosol family/classification. A passing review is not allocation or dispatch; allocation requires a separate post-review Issue #60 marker after the matching WRITE_QUIET fence is closed.
