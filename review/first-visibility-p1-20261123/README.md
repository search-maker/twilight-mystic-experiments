## Finite proposed pilot
Maximum 2 approved nonprotected sites; maximum 2 independently reporting consenting adult observers/site; maximum 3 target stars/site preselected by catalog snapshot/known V magnitude and predicted altitude/azimuth **before** any outcome; at most **12 site-evenings or 30 calendar days**, whichever first; zero purchases, solver dispatch or paid obligations. A site-evening, not a star/event, is the clustering unit. Keep ALL attempted evenings including cloudy, left-censored (already seen), right-censored (never seen) and interrupted nights, even when ineligible for strict onset. Taylor/Ann Arbor and Jerusalem protected data are entirely excluded.

Only unaided eyes (ordinary corrective glasses permitted). Never view Sun. Observer adapts >=600 seconds before strict-quality check, with adaptation start UTC and all screen/light exposure logged. Provide a target direction card **without a predicted first-visible time**. UTC clock error <=5s, repeated pre-detection NO reports at 15–30s cadence, first YES, then CONFIRM <=60s. Strict interval width (last NO -> first YES) <=60s. Missing earlier NO is *left-censored*, NOT a first-onset time. Any binocular/telescope detection is NOT an unaided sighting. Event cards conceal predictions throughout enrollment and observation; no outcome-based target selection.

Raw event fields: pseudonymous observer/site IDs; independently verified opt-in consent/site permission; HIP/HD/HR, V magnitude/catalog revision; UTC check times and original device error; site lat/lon/height/coordinate error/target horizon mask (private), star alt/az, solar depression and explicit ephemeris/frame; target cloud and whole-sky cloud; Moon; local lighting, adaptation, temperature/humidity; aerosol AOD550 with original provenance/QC or **explicit null**; any SQM with distinct UTC, az/alt, FWHM/passband/calibration. A zenith-only SQM or SG_088 at 90 degrees cannot validate a <=80-degree target direction nor a human first-sighting event.

**Custody and blinding:** Independent custodian stores personal consent and precise locations outside public GitHub, issues random tokens and securely logs consent receipts. Coordinator *before any observing* fixes approved science-model SHA, target/site/catalog/input-source selection, nonprotected case manifest, ephemeris/geometry, analysis, uncertainty, seeds and finite budget; writes an immutable dated prediction manifest and its SHA to a coordinator-only store. Observers never see predictions. On finishing each evening, hash raw append-only files and attempted-night census before custodian unlocks predictions; source corrections preserved as new version, not silently overwritten. Manifest must include event ID, pseudonymous observer/site IDs, original raw URI+SHA256+length, UTC ingestion, consent/site-permission receipt hash (not identity), raw times, data source/QC versions, calculation software SHA. **Currently zero manifest entries.**

**Fixed pilot-only decision:** >=8 high-quality NOT_SEEN -> first YES -> CONFIRM brackets from >=4 independent site-evenings counts as *feasibility only*. Otherwise `PILOT_FEASIBILITY_INSUFFICIENT`. Neither passes scientific domain validation. Prediction errors are forbidden until a correct actual frozen scientific model SHA and outcome data are available; unsupported 10.5–16 degrees returns `null`, >16 degrees V1 out-of-domain. Any confirmatory accuracy/promotion requires separate prospectively approved sample size, error and uncertainty acceptance limits, independent blinded observation and no tuning after outcome.
